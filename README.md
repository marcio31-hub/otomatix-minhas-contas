# OTOMATIX PWA

Envie **todos os cinco arquivos** deste pacote para a raiz do repositório `otomatix-minhas-contas` no GitHub, substituindo `index.html` e mantendo os outros arquivos.

Depois de publicar, abra o site no Chrome Android, atualize e use o menu ⋮ > Instalar app.

**Segurança:** este pacote não contém os 151 lançamentos. Os dados devem ser carregados apenas após autenticação no Supabase. Faça backup JSON antes de alterar o aplicativo.

O service worker guarda somente arquivos públicos de interface; não armazena respostas da API. A tela pode abrir sem internet, mas login e sincronização exigem conexão.
